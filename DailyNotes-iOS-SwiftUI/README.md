# DailyNotes

SwiftUI iOS app (iOS 17.0+) using SwiftData.

## Features
- Auto-creates today's structured note from a user-editable template
- Month calendar showing completion (tap to open/create)
- History with search
- Export to CSV or PDF via Share Sheet
- Optional daily reminder

## Getting Started
1. Open **DailyNotes.xcodeproj** in Xcode 15+.
2. In target Signing & Capabilities, set your Team and a unique Bundle Identifier.
3. Run on an iOS 17+ simulator or device.
